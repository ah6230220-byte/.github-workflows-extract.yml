# Telegram Bot Starter

## الملفات
- `bot.py`: كود البوت.
- `requirements.txt`: المكتبات المطلوبة.
- `.env.example`: مثال إعدادات البيئة.

## التشغيل محلياً
1. ثبّت Python 3.10 أو أحدث.
2. أنشئ بوتاً من BotFather وخذ BOT_TOKEN.
3. اعرف رقم Telegram ID الخاص بك وضعه في ADMIN_IDS.
4. انسخ `.env.example` إلى `.env` وعدّل القيم.
5. ثبّت المكتبات: `pip install -r requirements.txt`
6. عيّن متغيرات البيئة من لوحة الاستضافة ثم شغّل: `python bot.py`

## أوامر الأدمن
- `/admin` لوحة التحكم
- `/block USER_ID` حظر مستخدم
- `/unblock USER_ID` فك الحظر
- `/broadcast نص الرسالة` إذاعة للمستخدمين غير المحظورين

## ملاحظات الاستضافة
- استخدم Worker/Background Process يدعم التشغيل المستمر.
- لا ترفع ملف `.env` إلى مستودع عام.
- تأكد أن قرص الاستضافة دائم حتى لا تضيع قاعدة SQLite عند إعادة النشر.
- لا تشغّل أكثر من نسخة polling في الوقت نفسه باستخدام التوكن نفسه.

هذا إصدار أساس لإدارة البوت. لم يتم تضمين أتمتة التفاعلات الوهمية أو تجاوز حماية تطبيق خارجي.
